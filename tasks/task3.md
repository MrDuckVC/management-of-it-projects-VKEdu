# Практическое задание №3

* **DDD**: Разделите всё ваше приложение на 4-5 доменных зон с краткими описаниями и глоссариями.
* **BDD**: Выберите 1 Критический путь MVP. Опишите его в формате Дано-Когда-Тогда: 1 сценарий успеха и 1 сценарий отказа.
* **Wireframes**: Набросайте квадратиками 2-4 ключевых экрана, по которым проходит пользователь в ваших сценариях из критического пути.
* **API-First**: Спроектируйте JSON-контракты (запрос и ответ) для 1–2 главных ручек.
